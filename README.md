# ERA5 Wind Analyzer (C++ / GDAL)

Приложение на C++ для чтения климатических данных реанализа ERA5 (формат GRIB) и вычисления характеристик ветра с использованием библиотеки GDAL. 
Проект выполнен в рамках тестового задания для исследовательской программы ФКН НИУ ВШЭ (проект TensorQL).

## Возможности

*   **Чтение формата GRIB:** Работа с бинарными файлами ERA5 (10m u-component и v-component of wind).
*   **Быстрый поиск по времени:** При инициализации создаются хэш-таблицы (`std::unordered_map`), которые ставят в соответствие временной метке индекс нужного растрового канала. Это дает доступ к данным за O(1).
*   **Геопривязка:** Перевод географических координат (широта/долгота) в индексы пикселей растра с помощью `GDALGeoTransform` и метода Крамера (позволяет корректно работать с обрезанными региональными датасетами).
*   **Вычисление метрик:**
    *   Скорость ветра (по теореме Пифагора).
    *   Направление ветра (через `atan2` с переводом математического угла в компасный азимут).
    *   Средняя удельная мощность ветра (`P` прямо пропорциональна `V^3`).
*   **Оптимизация I/O:** При сборе статистики данные читаются целыми слоями (`ReadRaster`), что минимизирует количество обращений к диску.

## Стек технологий
*   C++ (C++20)
*   GDAL (Geospatial Data Abstraction Library)
*   CMake

## Сборка и запуск

Для сборки потребуется установленная библиотека GDAL (в Ubuntu: `sudo apt-get install libgdal-dev`).

```bash
# Клонирование репозитория
git clone https://github.com/sparrow213egida/era5-wind-analyzer.git
cd era5-wind-analyzer

# Сборка
mkdir build && cd build
cmake ..
make

# Запуск
./era5-wind-analyzer
